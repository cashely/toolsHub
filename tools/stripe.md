# Stripe

> 为互联网业务提供支付与商业基础设施。

## 工具介绍

Stripe 提供从收单、订阅、开票到跨境付款的完整支付能力，以开发者友好的 API 和完善的 SDK 著称，被全球大量 SaaS 与电商平台使用。

## 核心功能

### 在线收款

支持信用卡、数字钱包与全球本地化支付方式。

### 订阅计费

周期计费、试用、优惠券与收入恢复。

### 防欺诈

Radar 基于机器学习实时识别欺诈交易。

## 适用场景

- SaaS 订阅收费
- 电商与平台收款
- 市场平台分账
