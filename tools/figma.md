# Figma

> 集设计、原型与交付于一体的协作式 UI 设计工具。

## 工具介绍

Figma 基于浏览器运行，支持多人实时协作编辑，覆盖界面设计、交互原型、设计系统管理和开发交付全流程。

## 核心功能

### 实时协作

多人同时编辑同一文件，评论与光标同步可见。

### Auto Layout

响应式布局能力，设计稿随内容自适应。

### 原型交互

直接在文件中串联高保真可交互原型。

## 适用场景

- 产品 UI/UX 设计
- 设计系统建设
- 跨职能协作交付
