# GitHub

> 全球最大的代码托管与开源协作平台。

## 工具介绍

GitHub 基于 Git 提供代码托管服务，并围绕 Pull Request、Code Review、Actions、Packages 构建了完整的研发协作平台。

## 核心功能

### 代码托管

公有 / 私有 Git 仓库与分支管理。

### Pull Request

代码评审、讨论、状态检查一体化。

### GitHub Actions

内置 CI/CD 流水线，自动构建测试部署。

## 适用场景

- 代码版本管理
- 开源项目协作
- 持续集成与部署
