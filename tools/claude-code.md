# Claude Code

> 终端里的 AI Agent，可理解代码库并自主完成开发任务。

## 工具介绍

Claude Code 是运行在终端中的智能编程 Agent，能够读取整个项目上下文、编辑文件、运行测试和命令，完成从修 bug 到实现新功能的完整开发流程。

## 核心功能

### 代码库理解

自动分析项目结构与依赖，回答关于代码库的问题。

### 自主执行

可以编辑文件、执行命令、运行测试并根据结果迭代。

### 多文件重构

跨文件理解关联关系，完成大规模重构。

## 适用场景

- 复杂功能开发
- 代码重构与迁移
- 问题排查与修复
- 自动化脚本编写
