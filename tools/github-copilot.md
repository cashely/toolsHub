# GitHub Copilot

> 实时代码补全与 AI 对话编程助手。

## 工具介绍

GitHub Copilot 深度集成 VS Code、JetBrains 等主流编辑器，根据注释和上下文生成整行或整块代码，并提供 Chat 与 Agent 模式。

## 核心功能

### 实时代码补全

根据上下文智能建议整行或整个函数。

### Copilot Chat

在编辑器内通过对话解释代码、生成测试和修复问题。

### 多编辑器支持

支持 VS Code、Visual Studio、JetBrains 系列等环境。

## 适用场景

- 日常编码提效
- 快速原型开发
- 学习新语言与框架
