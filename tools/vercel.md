# Vercel

> Git 推送即上线的前端云平台。

## 工具介绍

Vercel 为 Next.js 等前端框架提供零配置部署，自动构建、全球边缘分发、预览链接与 Serverless 能力一体化。

## 核心功能

### Git 集成

推送代码自动触发构建与部署。

### 预览部署

每个 Pull Request 自动生成独立预览地址。

### 边缘网络

全球 CDN 与边缘函数，低延迟访问。

## 适用场景

- 静态站与前端应用托管
- Jamstack 项目部署
- 快速产品验证
