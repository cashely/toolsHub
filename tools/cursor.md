# Cursor

> AI 驱动的代码编辑器，帮助开发者更高效地编写和理解代码。

## 工具介绍

Cursor 是一款基于 AI 能力的代码编辑器，深度集成多种大模型，支持代码生成、智能补全、代码理解和 Agent 编程。

## 核心功能

### AI 代码生成

通过自然语言描述需求，生成对应代码。

### Agent 模式

理解项目结构、自主执行多文件修改并完成开发任务。

### 代码补全

结合项目上下文提供行内智能补全。

## 适用场景

- 日常软件开发
- AI 辅助编程
- 代码重构与项目理解
