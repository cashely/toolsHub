# Windsurf

> 基于 Cascade Agent 的 AI 协作编程编辑器。

## 工具介绍

Windsurf（原 Codeium 团队出品）将编辑器与 AI Agent 深度结合，Cascade 能够感知代码库上下文，自动完成多步编辑与终端任务。

## 核心功能

### Cascade Agent

自动规划并执行跨文件修改、命令运行等多步任务。

### 上下文感知

实时理解代码库变更，保持编辑一致性。

### 流畅补全

提供低延迟的单行与多行代码补全。

## 适用场景

- AI 辅助全流程开发
- 多文件联动修改
- 快速项目搭建
