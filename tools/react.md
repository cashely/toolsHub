# React

> 用于构建用户界面的声明式 JavaScript 库。

## 工具介绍

React 由 Meta 开发维护，通过组件化和虚拟 DOM 让开发者可以高效构建复杂的交互式前端界面，周边生态极为丰富。

## 核心功能

### 组件化开发

以可复用组件组织界面逻辑。

### Hooks

通过函数式 Hook 管理状态与副作用。

### 服务端渲染

配合 Next.js 等框架支持 SSR 与全栈开发。

## 适用场景

- 单页应用开发
- 中后台与仪表盘
- 跨端（React Native）应用
