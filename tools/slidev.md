# Slidev

> 为开发者打造的 Markdown 演示文稿工具。

## 工具介绍

Slidev（Slide + Dev）是一个专注于开发者群体的演示文稿工具：幻灯片内容写在一个 `slides.md` 文件里，用 Markdown 组织，由 Vite、Vue 3 和 UnoCSS 驱动渲染。它兼顾了 Markdown 的内容效率与现代网页的视觉表现力，代码演示能力尤其突出，支持在幻灯片中直接展示、编辑甚至运行代码。项目以 MIT 协议开源。

## 核心功能

### Markdown 驱动内容

用分隔线 `---` 分页，支持 Frontmatter 配置布局与样式；可把幻灯片拆成多个文件复用，并用 Prettier 插件统一格式。

### 开发者友好的代码呈现

基于 Shiki 的精准语法高亮，支持行号、点击行高亮、代码差异对比、TwoSlash 悬停类型提示；内置 Monaco 编辑器，可在放映时编辑、运行代码，还有类似 Keynote Magic Move 的代码过渡动画。

### 丰富的视觉与组件

内置主题系统并支持本地弹出自定义；可直接使用海量开源图标集，支持 Mermaid / PlantUML 图表、LaTeX 公式、画布标注、可拖动元素和 Vue 组件嵌入。

### 演示与导出

提供演讲者模式、备注、计时器、摄像头画中画、演示录制、远程控制与远程访问；可导出 PDF、可部署的静态 SPA、PNG 以及 PPTX。

## 适用场景

- 技术分享、会议演讲中需要大量展示代码与实时编码
- 开发者用 Git 版本化管理幻灯片内容与主题
- 将幻灯片作为静态网页部署分享，或导出 PDF/PPTX 分发
