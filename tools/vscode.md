# Visual Studio Code

> 微软推出的免费开源代码编辑器，插件生态极其丰富。

## 工具介绍

Visual Studio Code（VS Code）是目前最流行的代码编辑器之一，内置调试、Git、智能提示，并通过扩展市场支持几乎所有语言和框架。

## 核心功能

### 智能编码

内置语法高亮、智能补全与代码导航。

### 扩展生态

海量插件支持语言、主题、工具链集成。

### 内置调试

直接在编辑器内断点调试并集成 Git。

## 适用场景

- 多语言软件开发
- 前端与全栈开发
- 远程与容器开发
