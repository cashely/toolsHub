# AI 编程工具合集

根据自己的使用习惯选择形态：喜欢图形化编辑器可以选择 Cursor、Copilot 或 Windsurf；偏好终端和自主 Agent 工作流则选择 Claude Code。

不同工具的定位各有侧重，可以根据项目类型和开发习惯搭配使用。
